# 📝 나만의 프롬프트 관리 프로그램 (Prompt Manager)

AI 프롬프트를 카테고리별로 체계적으로 분류하고, 검색 및 즐겨찾기 기능으로 편리하게 관리할 수 있는 파이썬 콘솔 애플리케이션입니다.

---

## 📌 프로젝트 소개
* **목적**: 자주 사용하는 LLM/AI 프롬프트를 한곳에 저장하고 카테고리별로 조회·검색·즐겨찾기 관리
* **작성자**: [Kwak-gif](https://github.com/Kwak-gif)
* **저장소**: [https://github.com/Kwak-gif/A1-1](https://github.com/Kwak-gif/A1-1)
* **개발 언어**: Python 3.10+ (외부 라이브러리 없이 순수 파이썬 표준 문법으로 구현)

---

## 🚀 실행 환경 및 방법

### 1. 요구 환경
* Python 3.10 이상
* Git

### 2. 저장소 복제 (Clone)
```bash
git clone https://github.com/Kwak-gif/A1-1.git
cd A1-1
```

### 3. 프로그램 실행
```bash
python prompt_manager.py
```

## ✨ 주요 기능 목록

| 번호 | 기능명 | 설명 |
|:---:|:---|:---|
| **1** | **프롬프트 추가** | 제목, 내용, 카테고리를 입력받아 새로운 프롬프트 등록 (빈 값 입력 방지 검증 포함) |
| **2** | **프롬프트 목록** | 등록된 전체 프롬프트를 번호, 카테고리, 즐겨찾기(`⭐`) 여부와 함께 출력 |
| **3** | **카테고리별 조회** | 특정 카테고리를 선택하여 해당 카테고리에 속한 프롬프트만 필터링 출력 |
| **4** | **프롬프트 검색** | 키워드를 입력받아 제목 또는 내용에 키워드가 포함된 프롬프트 검색 |
| **5** | **프롬프트 상세 보기** | 번호를 입력받아 해당 프롬프트의 전체 본문과 세부 정보 확인 |
| **6** | **즐겨찾기 관리** | 특정 번호의 프롬프트를 즐겨찾기 등록/해제 (토글 방식) |
| **7** | **즐겨찾기 목록** | 즐겨찾기(`⭐`) 등록된 프롬프트만 모아서 출력 |
| **0** | **종료** | 안내 메시지와 함께 안전하게 프로그램 종료 |

## 📂 프롬프트 카테고리 체계

| 카테고리명 | 설명 및 활용 예시 |
|:---|:---|
| **텍스트 생성** | 블로그 글 작성, 이메일 초안 작성, 텍스트 요약 등 |
| **이미지 생성** | 썸네일 제작, 일러스트레이션 생성, 미드저니/DALL-E 프롬프트 등 |
| **영상 생성** | 영상 기획 대본, 쇼츠/릴스 콘티, 비디오 생성 AI 프롬프트 등 |
| **페르소나** | IT 컨설턴트, 마케터, 카피라이터 등 특정 전문가 역할 설정 프롬프트 |
| **자동화** | 반복 업무 자동화, 정규표현식 작성, 엑셀 매크로/파이썬 스크립트 작성 등 |
| **기타** | 그 외 다양한 자유 목적의 프롬프트 |

---

## 💡 기본 등록 데이터 (Default Data)

프로그램 실행 시 즉시 테스트할 수 있도록 기본 프롬프트 3종이 내장되어 있습니다:
1. `[텍스트 생성]` 블로그 글 작성 도우미 (즐겨찾기 ⭐ 등록)
2. `[이미지 생성]` 제품 썸네일 생성
3. `[페르소나]` IT 컨설턴트 페르소나

* **커밋 횟수**: 10회 이상의 체계적인 기능별 커밋 이력 유지
